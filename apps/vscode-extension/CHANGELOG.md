# Changelog

## 0.1.0 — MVP

- Interactive local-first code-flow diagrams for TypeScript and JavaScript.
- Bidirectional graph/editor navigation with source highlighting.
- On-demand expansion of resolvable calls, including cross-file definitions.
- Configurable live refresh, expansion depth and graph orientation.
- Local workspace session recovery when source files are unchanged.
- Automated analyzer, graph, integration and benchmark tests.
